# Caption + Hashtag Template

## Caption ka formula (har platform alag)

```
[HOOK LINE — 1 line, adhoori]
↓
[KAHANI KA CORE — 2-3 chhoti lines, end nahi batana]
↓
[MORAL — ek line]
↓
[SAWAL — comment trigger]
↓
[HASHTAGS]
```

---

## YouTube Shorts

**Title (60 char ke andar, keyword + emoji):**
```
[Emotional keyword] + [curiosity gap] + emoji + #shorts
```
Examples:
- `Maa ne kyu kaha "maine kha liya" 😢 #shorts`
- `Sabziwale ne 10 rupay kam liye... phir jo hua 🥺 #shorts`
- `Baap ke joote 6 saal purane the 👞💔 #shorts`

**Description:**
```
[1st line = repeat of hook, keyword ke saath]

Aaj ki kahani: [2 line summary]

Moral: [ek line]

Aapke ghar me aisa kabhi hua hai? Comment me zaroor batana. 👇

#hindistories #urdukahani #moralstories #emotionalstory #shorts
```

**Pinned comment:**
```
Agar ye kahani aapke dil ko chhoo gayi, to apni ammi ko ye video bhej dena. 💛
Aur batao — aapke ghar ki kaun si baat aapko yaad aa gayi?
```

## Hashtag sets (rotate karo, har video me same mat rakho)

**Set A — core (har video me 4)**
```
#hindistories #urdukahani #moralstories #emotionalstory
```

**Set B — desi family**
```
#desifamily #amma #rishtey #gharkikahani #saasbahu #beti
```

**Set C — platform reach**
```
#shorts #reels #fyp #reelsindia #reelspakistan #storytime #viral
```

**Set D — topic-specific (episode ke hisaab se 2–3)**
```
EP01 (maa)        → #amma #maa #motherslove
EP02 (paisa)      → #imaandari #paisa #insaaf
EP06 (beti)       → #betipadhao #girlpower #aurat
EP20 (diary)      → #diary #puranikahani #nostalgia
```

**Rule:** har video me = Set A (4) + Set C (3) + Set D (2–3) = 9–10 hashtag.

## Comment reply templates

| Comment type | Jawab |
|---|---|
| "Ye mere ghar ki kahani hai" | "Bilkul... aur isi liye main ye kahaniyan sunati hoon 💛" |
| "Part 2 chahiye" | "Diary ka agla panna — kal raat 8:30 🫶" |
| "Aap AI ho?" | "Main Noor hoon — mohalle ki kahaniyan sunane wali. Kahani asli hain 😊" |
| Negative/troll | Reply mat karo, ya sirf "Shukriya aapke waqt ka 🙏" |
| Apni kahani sunaya | "Ye kahani mujhe pasand aa gayi — agle hafte ise sunaungi, aapka naam ke saath" |

> **Aakhri wala sabse important hai.** Audience ki kahani video banao —
> isi se community banti hai aur content kabhi khatam nahi hota.
