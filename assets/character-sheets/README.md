## Banane ka rule

1. Sab images **ek hi session me** banao (lighting/skin tone match hoga)
2. Imagen se 4–6 variations lo, sabse natural chuno
3. Chuni hui image ko yahan save karo
4. Phir Flow ke Ingredients panel me upload karke **naam de do**
5. Uske baad kabhi change mat karo — 100 videos tak yahi chehra
